# MTU
 Maximum Transfer Unit. 프레임의 형식에 정의된 필드 값의 하나. 데이터그램이 프레임 속에 캡슐화 될 때, 데이터그램의 크기는 MTU보다 작아야 한다.

# TTL
 Time To Live는 라이프 타임이라고도 하며, 네트워크에서 IP 데이터그램이 활동할 수 있는 최대 홉이다.

# 검사합
 check sum은 패킷의 전달 중에 발생할 수 있는 오류에 대한 보호를 수행하기 위해 사용되는 오류 검출 방법이다.

# 단편화
 데이터그램이 라우터를 통해서 다른 네트워크로 전달될 때 데이터그램의 크기를 MTU값 이하로 작게 나누어 전송해야 하므로 단편화, 즉 패킷을 분할한다.

 IP 프로토콜 개념
	IP는 상위 계층에 연결하는데 필요한 데이터 전송과 경로선택 기능을 제공하고, 라우팅 프로토콜을 사용하여 최적의 경로를 선택한다.
	패킷을 수신지까지 최선을 다해서 전송하지만, 전송 완료까지 신뢰성은 보장하지 않는다.
	IP는 간단한 오류 검사 기능만 있고, 비연결형 프로토콜이다.
IP 데이터그램의 구조
	IP헤더 크기는 최대 60바이트(기본 20byte, 옵션 40byte)로 패킷을 전달하는데 필요한 모든 정보를 포함한다.
	IP 헤더 필드는 버전(VER), 헤더 길이(HLEN), 서비스 유형(Service type), 전체 길이(Total Length), 식별자(identification), 플래그(flags), 단편화 옵셋(fragmentation offset), TTL(Time To Live), Protocol, 헤더 검사합(Header check sum), Source IP, Destination IP 등이다.
IP 데이터그램의 단편화
	데이터그램이 라우터를 통해서 다른 네트워크로 전달될 때 데이터그램의 크기를 MTU값 이하로 작게 나누어 전송해야 하므로 단편화 즉, 패킷을 분할한다.
	IP 헤더에서 단편화와 관련된 필드는 식별자, 플래그, 단편화 옵셋 이다.
IP 데이터그램의 검사합
	검사합(check sum)은 데이터그램의 전달 중에 발생할 수 있는 오류에 대한 보호를 수행하기 위해 사용되는 오류 검출 방법이다.
	IP에서 헤더 검사합(Header check sum)은 데이터그램 내의 헤더만 검사하고, 데이터는 포함하지 않는다.
