# ICMP
 Internet Control Message Protocol, 인터넷 제어 메세지 프로토콜

# Error reporting 메시지
 오류 보고(Error reporting) 메시지는 라우터나 목적지 호스트가 IP 패킷을 처리하는 도중에 발견하는 문제를 보고한다.

# Query 메시지
 쿼리 메시지는 호스트나 네트워크 관리자가 라우터나 다른 호스트로부터 특정 정보를 획득시 사용한다.

# 그리니치 표준시
 세계 표준시로서 ICMP에서는 두 시스템간에 타임스탬프 요청과 응답 메시지를 사용하여 IP 데이터그램이 오고 가는데 필요한 왕복 시간을 결정하는데 사용한다.

# 학습 목표
 네트워크 계층의 ICMP의 개념과 기능을 설명할 수 있다.
 ICMP 오류보고 메시지의 다양한 유형을 설명할 수 있다.
 ICMP 조회 메시지를 설명할 수 있다.

# 학습 내용
ICMP 개요
	ICMP(Internet Control Message Protocol)는 인터넷 제어 메시지 프로토콜로, IP는 신뢰성이 없는 프로토콜이므로 이 단점을 보완하기 위하여 설계 되었다.
	네트워크의 호스트나 라우터에서는 예상치 못한 상황이나 오류가 발생하는데, 발생한 오류를 송신 측으로 전송하는데 사용하는 프로토콜이 ICMP이다.
	ICMP 메시지는 크게 오류 보고(Error reporting)메시지와 조회(Query)메시지로 분류 된다.
	ICMP 메시지는 8바이트 헤더와 가변 길이 데이터 부분을 가지고 있다.
ICMP 오류보고 메시지
	ICMP 오류 메시지의 주 임무는 오류를 수정이 아니라 오류 내용에 관한 보고만 한다.
	ICMP는 다섯 가지 오류 유형을 처리한다.
	목적지 도달 불가능
	발신지 억제
	시간 경과
	매개변수 문제
	재지정
ICMP 조회 메시지
	ICMP 조회(query)메시지는 호스트나 네트워크 관리자가 라우터나 다른 호스트로부터 특정 정보 획득 시 사용한다.
	ICMP는 4개의 조회 메시지를 통하여 수행이 가능하다.
	에코 요청과 응답
	타임스탬프 요청과 응답
	주소 마스크 요청과 응답
	라우터 간청과 응답
	현재 에코 요청과 응답, 타임스탬프 요청과 응답 메시지만 사용되고 있다.
