# IPv6
 IPv6는 IPv4의 단점을 개선하려는 목적으로 개발된 IP의 새로운 버전이다.

# Flow Label
 IPv6에서 Flow Label은 데이터 흐름을 위한 특별한 처리를 제공하며 실시간 오디오와 비디오를 전송하는 곳에 쓰일 수 있다.

# ICMPv6
 TCP/IP 프로토콜 그룹에서 수정된 ICMP버전6

# AnyCast
 IPv6에 사용되는 주소 유형으로 애니캐스트 통신은 여러개의 서버들이 질문이 응답하는데 사용된다

IPv6 프로토콜
	IPv6는 IPv4의 단점을 개선하려는 목적으로 개발된 IP의 새로운 버전이다.
	IPv6 주소 길이는 128비트로, IPv4 주소와 비교하면 주소 공간 길이가 4배 증가한 것이다.
	IPv6 주소는 긴 주소를 쉽게 읽을 수 있도록 콜론(:)으로 나누어 각 필드를 16진수 4개로 표현하는 콜론 16진 표기법을 사용한다.
	IPv6 필드에서 플로 레이블(flow label)은 데이터의 흐름을 위한 특별한 처리를 제공한다.
	IPv6 주소 공간은 다양한 크기의 여러 공간으로 나누며, 각 블록은 특수한 목적에 사용된다.
	IPv6 주소 유형은 유니캐스트(Unicast), 에니캐스트(Anycast), 멀티캐스트(Multicast)가 있다.
ICMPv6 프로토콜
	ICMPv6는 ICMPv4와 목적과 방법이 동일하며, TCP/IP 프로토콜 그룹에서 수정된 ICMP 버전 6이다.
	ICMPv6 메시지는 정보 메시지, 오류 보고 메시지, 이웃 발견 메시지, 그룹 멤버십 메시지로 분류된다.
	ICMPv6의 주 임무 가운데 하나가 버전4와 마찬가지로 오류 보고이다.
	2개의 메시지, 즉 에코 요청 메시지와 에코 응답 메시지가 정보 메시지로 분류된다.
