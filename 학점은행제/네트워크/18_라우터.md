 원하는 목적지까지 가능한 경로들 중에서 최선의 경로를 결정하여 주는 기능

# AS
 Autonomous System : 라우팅 정책이 같은 라우터와 네트워크들의 집합

# Routing 프로토콜
 라우터 사이에 라우팅 정보를 교환하기 위해 사용하는 프로토콜. 네트워크에서 빠른 길을 찾도록 해줌.

# Static routing
 네트워크 관리자가 직접 목적지별로 라우팅을 지정해 주는 방식.

# 학습 목표
라우터의 동작 방식을 설명할 수 있다.
2	스태틱 라우팅과 다이나믹 라우팅에 대하여 설명할 수 있다.

# 학습 내용
라우터(Router)
2	라우팅(Routing)
3	스태틱 라우팅

라우터(Router)
	라우터는 IP주소를 바탕으로 데이터가 수신지까지 갈 수 있는 경로를 검사하여 효율적인 경로를 선택하는 라우팅을 수행한다.
	라우터에서는 이용자 모드, 운영자 모드, Global Mode, 인터페이스 모드, 라우터 모드가 있다.
	라우터의 역할은 Broadcast domain을 나누고, 라우팅 프로토콜을 이용하여 Routing 테이블을 구성하고, 스위칭 기능을 수행한다.
	라우터에서 인터페이스 모드 변경은 Global 모드인 Router(config)#에서 해당 인터페이스를 입력하고, 라우터 모드 변경은 라우팅 프로토콜을 입력한다.
라우팅(Routing)
	라우팅(Routing)이란 원하는 목적지까지 가능한 경로들 중에서 최선의 경로(best path)를 결정하여 주는 기능이다.
	정적 라우팅(static routing)은 관리자가 라우팅 테이블을 직접 작성한다.
	동적 라우팅(dynamic routing)은 라우팅 프로토콜에 의하여 라우팅 정보를 주고 받아서 라우팅 테이블이 생성된다.
	거리 벡터 라우팅은 라우터간의 모든 라우팅 정보를 주기적으로 인접 라우터로 부터 주고 받는다.
	링크 스테이트 라우팅은 SPF Algorithms을 사용하여 목적지까지 가능한 경로들 중에서 최선의 경로(best path)를 결정한다.
라우팅 프로토콜의 특성
	스태틱 라우팅(Static routing)은 네트워크 관리자가 직접 목적지별로 라우팅을 지정해 주는 방식이다.
	스태틱 라우팅은 라우팅 테이블을 작성하는데 오버헤드가 없으나, 오류 발생 가능성이 높고, 신속하고 정확한 대처가 어렵다.
	설정한 스태틱 루트가 정상적으로 작동하는지 ping테스트를 수행하여 확인한다.
	라우터의 라우팅 테이블 확인은 ‘show ip route’ 명령어로 확인한다.
