# RIP
 Routing Information Protocol : 거리 벡터 프로토콜. 각 라우터에서 자신이 갖고 있는 전체 라우팅 테이블을 주기적으로 인터페이스로 브로드캐스팅함.

# OSPF
 Open Shortest Path First : 계층화된 라우팅 동작을 수행하며, 각 라우터는 로컬 인터페이스의 연결 상태 정보를 지역 내의 모든 라우터에게 Advertising함

# BGP
 Border Gateway Protocol 는 AS(Autonomous System)간의 라우팅 정보를 교환하기 위한 프로코톨이다. BGP는 경로 선택 알고리즘인 MED(Multi Exit Dircriminator)를 사용함

# 벨만 포드 알고리즘
 그래프 최단 경로를 구하는 알고리즘으로 하나의 정점에서 출발하는 최단 거리를 구한다. 거리 벡터 라우팅 프로토콜에 사용된다.

# 다익스트라 알고리즘
 그래프의 한 정점에서 모든 정점까지의 최단 거리를 각각 구하는 알고리즘으로 링크 스테이트 알고리즘에 사용됨.

라우팅 프로토콜의 특성
	라우팅 프로토콜은 Router 사이에 라우팅 정보를 교환하기 위해 사용하는 프로토콜이다.
	라우팅 프로토콜에 따라 적절한 루트를 선택하는 기준이 다르다.
	라우팅 프로토콜의 종류
	IGP(Interior Gateway Protocol)는 AS 내에서 사용
	DISTANCE-VECTOR : RIP, IGRP
	LINK-STATE : OSPF, ISIS
	EGP(Exterior Gateway Protocol)는 AS 간에 사용
	EGP, BGP
거리 벡터 라우팅
	거리 벡터 라우팅은 Bellman-Ford 알고리즘을 사용하며, 각 라우터는 자신의 전체 라우팅 테이블을 주기적으로 전 인터페이스로 브로드캐스팅한다.
	간단하여 운영하기가 쉽고 라우터의 CPU 사이클 및 메모리를 적게 소모한다.
	거리 벡터 라우팅 프로토콜의 대표적인 예로는 RIP를 들 수 있다.
	RIP(Routing Information Protocol)는 메트릭으로 HOP 카운트를 사용하며 최대 15Hop으로 제한된다.
	RIP 버전1은 Classful Routing을 사용하며, RIP 버전2는 VLSM을 지원한다.
링크 스테이트 라우팅
	링크 상태(Link-state) 라우팅은 네트워크 구조에 대한 전체 데이터베이스를 개별 라우터가 가진다.
	네트워크의 변화가 생길 때 마다 변경된 Link State 정보를 알린다.
	SPF 알고리즘으로 모든 목적지 네트워크에 대해 Shortest Path Spanning Tree를 결정한다.
	OSPF는 링크 스테이트 라우팅 프로토콜로, 전체 네트워크를 에어리어(Area)로 구성해서 라우팅 정보 양을 줄이고, 라우터를 효율적으로 운영할 수 있게 한다.
