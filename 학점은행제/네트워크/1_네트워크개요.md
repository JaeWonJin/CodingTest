# 프로토콜
 - 데이터 통신을 원활하게 하기 위한 미리 약속한 전송규약(규칙)
# LAN
 - (Loacl Area Network)근거리 네트워크는 범위가 건물이나 특정 지역인 네트워크로 유선 케이블, 적외선 링크, 무선 송수신기등을 이용하여 통신한다.
# MAN
 - (Metropolitan Area Network)대도시 네트워크는 대도시 정도의 넓은 지역을 연결하기 위한 네트워크 구성형태
# WAN
 - (Wide Area Network)광역 네트워크는 지리적으로 멀리 떨어진 곳에 위치하는 통신 장비들 사이에 데이터를 전송할 수 있는 서비스를 제공하는 망.

# ASCII 코드
 - American Standard Code for information interchange 미국 정보 교환 표준 코드
 - 7비트 + 1비트(패레디 비트 : 오류를 검증하기 위한 비트) = 8비트

# 네트워크
 - 모뎀이나 LAN 케이블, 무선 매체 등 통신 설비를 갖춘 컴퓨터를 서로 간 연결하는 체계적인 통신망을 의미
 - 컴퓨터, 전송 매체, 네트워크 접속장치(송수신기 등)으로 구성됨.

# 인터넷
 - 전 세계에 산재되어 있는 컴퓨터 간의 정보를 공유하기 위하여 컴퓨터와 통신망을 연결해 놓은 컴퓨터 네트워크

# TCP
 - Transmission Control Protocol
 - 프로세스간 연결 흐름 제어, 오류 제어

# IP
 - Internet Protocol
 - 패킷의 경로 설정

# 프로토콜 계층화
 - 통신이 복잡할 때는 여러 계층을 두어 서로 다른 계층 간에 임무를 나눌 수 있음
ex : 인터넷의 기본 프로토콜은 TCP/IP, 웹사이트의 웹페이지를 볼 수 있는 HTTP, 인터넷 이메일을 주고 받으려면 SMTP나 POP3 프로토콜
, 데이터 파일을 업로드 하거나 다운로드 할때 사용하는 FTP 프로토콜

# 프로토콜의 주요 요소
 ## 구문(Syntax)
  - 데이터의 구조나 형식, 데이터에 표현되는 순서
 ## 의미(Semantics)
  - 비트들의 영역별 의미로서 특정 패턴을 어떻게 해석하고, 이를 기반으로 어떤 동작을 할 것인가를 결정
 ## 타이밍(Timing)
  - 언제 데이터를 전송하고, 얼마나 빨리 전송할 것인가에 해당
