# OSI
 - 통신 기능을 7계층으로 분류하여 각 계층마다 프로토콜을 규정한 규격을 OSI7(Open System Interconnection)모델이라고 한다.
# IP주소
 - 현재 인터넷에 연결된 호스트를 유일하게 식별할 수 있는 32비트의 IP주소를 인터넷 주소라고 한다.
# MAC주소
 - 링크 주소 또는 통신망에서 정의된 노드의 물리 주소로서, 6바이트(48비트)이다.

# 헤더
 - 데이터의 앞 부분에 붙이는 제어 정보. 

# 캡슐화
 - 데이터 앞에 헤더를 붙이는 것. OSI 계층이 내려갈수록 각 계층에 해당하는 헤더가 추가됨
