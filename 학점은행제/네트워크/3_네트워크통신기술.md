# 유니캐스트
서버와 클라이언트가 1대1로 통신하는 형태

# 브로드캐스트
네트워크에 연결된 모든 호스트들에게 데이터를 전송. 호스트가 많을수록 네트워크 트래픽이 증가함

# PCM (Pulse Code Modulation)
아날로그 신호를 디지털 신호로 바꾸기 위해 사용되는 변환 방식. 
아날로그 신호 + PAM표본화 -> PAM신호
PAM신호 + 양자화 -> PCM 신호
PCM신호 + 부호화 -> 디지털 신호
 ## 표본화 (= 채집화) Sampling
  음성과 같은 아날로그 신호를 디지털화 하기 위해서 일정한 시간 간격으로 신호간격을 표본화(일정 시간 간격으로 셈플값을 추출)
   Pulse Amplitude Modulation (펄스 진폭 변조) 
 ## 양자화 Quantization
  표본화를 거친 양자화 신호 PAM을 디지털화 하기 위해 각 표본값을 어떠한 단계의 레벨에 가장 가까운 숫자로 근사화 하는 과정(유리수를 정수로 근사화하기)
 ## 부호화 EnCoding
  양자화를 거친 값을 전송을 위한 디지털 신호인 2진수 비트 값으로 변환함 (근사된 정수를 2진수로 변환)

AD 컨버터 : 아날로그 -> 디지털 신호로 변환
DA 컨버터 : 디지털 -> 아날로그 신호로 변환

# 동기화
송신 측에서 전송한 데이터의 각 비트를 수신 측에서 정확하게 수신할 수 있도록 속도 차이(클록오차)를 맞추는 것

# 데이터 통신 기술
	PCM방식은 아날로그 신호를 디지털 신호 데이터로 바꾸기 위해 가장 널리 사용되는 변환 방식으로 표본화, 양자화, 부호화 단계로 이루어진다.
	장치사이의 데이터 전송 방식은 직렬 전송과 병렬 전송으로 분류할 수 있다.
	동기화(Synchronization)는 적절한 방법으로 송신측에서 전송한 데이터의 각 비트를 수신측에서 정확하게 수신할 수 있도록 한다.
# 네트워크 통신 방식
	서버는 클라이언트(사용자)한테 요청 받아 서비스를 제공하는데 이렇게 구성된 시스템을 ‘클라이언트/서버 시스템’이라고한다.
	LAN에서 통신하는 방식으로 유니캐스트, 멀티캐스트, 브로드캐스트가 사용된다.
	전송 방향에 따른 통신 방식은 두 장치 간에 데이터를 전송할 때 데이터 전송 방향에 따라 분류하는데 단방향(simplex)통신과 전이중(full-duplex)통신, 반이중(half-duplex)통신으로 나눌 수 있다.
