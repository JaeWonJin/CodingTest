# 패리티 비트
 정보의 전달 과정에서 오류가 생겼는지를 검사하기 위해 추가된 비트. 
 패리티 비트 검사는 전송하는 데이터마다 패리티 비트라 불리는 중복 비트를 데이터 단위에 덧붙인다.

# CRC
 Cyclic Redundancy Check(순환 중복 검사) : 정확하게 오류를 검출하려고 사용하는 방식

# ARQ
 Automatic Repeat reQuest(자동 반복 요청) : 통신상에서 오류가 발생했을 때 수신측은 오류 발생을 송신측에 알리고
 송신측은 오류가 발생한 프레임을 재전송하여 오류를 수정하게 된다.

# 생성다항식
 Polynomial : CRC 발생기에서 사용. 0과 1의 스트링보다는 대수 다항식으로 표현하는 방법.


# 통신에서 오류의 발생
	오류란 보낸 데이터와 받는 데이터 사이에 차이가 있는 경우를 말한다.
	수신 측으로 전송한 데이터는 송신 측의 데이터와 동일해야 하지만, 다양한 원인 때문에 데이터 오류가 발생할 수 있다.
	오류 형태는 단일비트오류, 다중 비트 오류, 집단 오류로 분류할 수 있다.

# 통신 오류 검출 기법
	네트워크 통신에서 많이 사용되는 오류 검출 방법은 패리티 검사(Parity check), 블록합 검사(Block Sum Check), 순환 중복 검사(CRC; Cyclic redundancy Check), 검사합(Checksum Check)이 있다.
	ARQ(자동 반복 요청(Automatic Repeat reQuest))방식은 통신상에서 오류가 발생했을 경우 수신측은 오류 발생을 송신측에 알리고, 송신측은 오류가 발생한 프레임을 재전송하여 오류를 수정하게 된다.
