# LAN 카드
 네트워크에 접속하기 위해 외부 네트워크와 빠른 속도로 데이터를 송수신할 수 있도록 컴퓨터 내에 설치하는 확장 카드

# 허브
 hub. 여러 단말기를 연결하여 접속하기 위한 네트워크 접속 장치로 여러개의 입력 및 출력 포트가 있다.

# 스위치
 컴퓨터에 할당되는 대역폭을 극대화하는 장치. 허브와 달리 근거리 통신망이 제공하는 대역폭을 모두 컴퓨터로 전송한다.

# 라우터
 서로 다른 네트워크 사이에 통신하는데 사용되는 장치. IP 주소를 바탕으로 데이터가 수신지까지 갈 수 있는 효율적인 경로를 선택하는 라우팅 기능을 수행함.

# 접속 장치로 연결된 네트워크 구조 설명

# 네트워크를 구성하는 접속 장치를 종류별로 설명.
 ## LAN 카드

 ## 허브
  물리 계층
 ## 스위치
  데이터 링크 계층

접속 장치로 연결된 네트워크
	네트워크를 구성하기 위해 호스트를 서로 연결하거나 인터넷을 구성하기 위하여 접속장치를 이용하여 네트워크를 구성한다.
	계층별로 가장 기본이 되는 하드웨어 접속장치는 다음과 같다.
	1계층 장치 : 허브, 리피터
	2계층 장치 : 스위치, 브리지
	3계층 장치 : 라우터
네트워크 접속 장치별 특징
	허브(hub)는 여러 단말기를 연결하여 접속하기 위한 네트워크 접속 장치로 여러 개의 입력 및 출력 포트가 있다.
	스위치는 컴퓨터에 할당되는 대역폭을 극대화하는 장치로, 허브와 달리 근거리 통신망이 제공하는 대역폭을 컴퓨터로 모두 전송한다.
	라우터는 서로 다른 네트워크 간에 통신하는 데 사용하는 장치로, IP 주소를 바탕으로 데이터가 수신지까지 갈 수 있는 효율적인 경로를 선택하는 라우팅 기능을 수행한다.
