# 멀티캐스팅
 multicasting 방식에서 송신호스트는 한 번의 데이터 전송으로 그룹 내 여러 호스트들에게 데이터를 전송할 수 있다.

# 브로드캐스팅
 네트워크에 연결된 모든 호스트들에게 데이터를 전송한다

# 토폴로지
 네트워크의 구성을 네트워크 토폴로지라고 하는데, 이는 네트워크에 연결되어 있는 노드와 링크가 물리적 혹은 논리적으로 연결되어 있는 방식을 말한다.

# 터미네이터
 버스형 구조는 모든 노드가 하나의 케이블에 연결되어 있는데, 케이블의 양 끝에는 터미네이터라는 장치를 붙여서 신호가 케이블로 되돌아오는 것을 막는다.

# 네트워크의 접속 형태


네트워크의 데이터 전송방식
	네트워크 연결 유형에서 유니포인트(Point-to-point)는 하나의 수신 호스트와 점대점 연결 방식으로 두장치 간의 전용링크를 제공한다.
	멀티포인트(Multipoint)방식은 다수의 수신 호스트와 연결하는 방식이다.
	멀티캐스팅 방식에서 송신호스트는 한 번의 데이터 전송으로 그룹 내 여러 호스트에게 데이터를 전송할 수 있다.
	브로드캐스팅 방식은 네트워크에 연결된 모든 호스트에게 데이터를 전송하는데 호스트가 많을수록 네트워크 트래픽이 증가하게 된다.
	네트워크 접속 형태
	네트워크 접속형태(토폴로지)는 네트워크에 연결된 여러 노드의 물리적인 배열이 아닌 상호연결 방법을 보여준다.
	성형구조는 가장 일반적인 네트워크 구성 형태로 허브 또는 스위치가 네트워크 중앙에 위치하여 다른 모든 노드를 연결한다.
	그물형은 네트워크가 복잡하고 많은 통신회선이 필요하기 때문에 비용이 많이 들지만 신뢰성이 높아 중요한 네트워크에 주로 사용한다.
