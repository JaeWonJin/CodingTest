# 패킷 교환
 Packet Switching방식에서 데이터는 네트워크로 전송되기 전에 패킷이라는 작은 조각들로 나뉘는데,
 패킷들은 고유한 번호가 있어 수신지에 전송되었을 때 원래의 데이터로 결합하여 재구성할 수 있다.

# MAC
 Media Acess Control은 데이터 충돌을 방지하려고 LAN에 연결된 모든 장치는 정의된 규칙에 따라 전송매체에 접근하는데,
 이를 매체 접근 제어라고 한다.

# CSMA/CD
 Carrier Sense Multiple Acess With Collision Detection는 반송파 감지 다중 접근/충돌 검출 방식으로 주로 버스형 통신망으로 알려진 이더넷에서 사용한다.

# 기가비트이더넷
 Gigabit Ethernet은 1Gbps 전송 속도를 지원하는 이더넷이다.

# 네트워크 통신망인 LAN, MAN, WAN의 특징을 설명할 수 있다.

# 교환 통신망의 교환 방식을 기술할 수 있다.


네트워크 통신망의 분류
	네트워크의 주요 통신망으로는 근거리 통신망(LAN), 대도시 통신망(MAN), 광역 통신망(WAN), 무선 LAN(WLAN) 등으로 분류한다.
	LAN은 빌딩이나 건물 내로 한정된 네트워크이다.
	MAN은 대도시 정도의 넓은 지역을 연결하기 위한 네트워크이다.
	WAN은 수백에서 수천 km이상의 매우 범위가 넓은 네트워크이다.
	데이터 충돌을 방지하려고 LAN에 연결된 모든 장치는 정의된 규칙에 따라 전송매체에 접근하는데, 이를 매체 접근 제어(MAC)방식이라고 한다.
교환 통신망
	교환 통신망은 통신망 노드의 교환과 전송 기능을 이용하여 데이터를 수신측까지 전송하는 통신망을 말한다.
	회선 교환(circuit switching)은 데이터를 전송하기 전에 물리적인 하나의 경로가 설정되며, 설정된 경로는 통신을 종료할 때까지 독점한다.
	메시지 교환(message switching)은 도착하는 메시지를 일단 저장한 후 다음 노드로 가는 링크가 비어 있으면 전송하는 방식이다.
	패킷 교환(packet switching)은 적당한 크기로 메시지를 분할하여 전송한다.
