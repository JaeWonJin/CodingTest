# Wi-Fi
 wireless fidelity(무선데이터 전송 시스템)의 줄임말. 

# WPA2
 옵션이나 키 입력 방식이 WEP 방식보다 간단하여 설정하기가 더욱 편한 최근 보안 표준 방식이다.

# CSMA/CA
 Carrier Sense Multiple Access/Collision Avoidance는 무선 환경에서 Station이 목적지로 데이터를 전송하기 위해 사용하는 프로토콜이다.

# SSID
 SSID는 무선 환경에서 연결하려는 네트워크를 알려주는 식별자로서 여러 Wi-Fi중에서 확실히 구분할 수 있도록 해준다

# 학습 목표
 무선 네트워크의 특징을 설명할 수 있다.
  무선 통신은 자유공간의 전파를 매체로 하여 정보 신호를 주파수 자원에 할당하여 전송하는 방식이다.
  무선 LAN은 다양한 정보와 자원을 공유할 수 있게 하는 LAN의 장점과 제약 없는 연결성 제공이라는 편리성을 동시에 제공한다.
  무선 통신 네트워크에서는 단말기의 이동이 자유롭다.
 IEEE 802.11 무선 네트워크의 규격을 설명할 수 있다.
  IEEE802.11은 미국국가표준을 개발하는 IEEE가 승인한 무선 LAN 표준화 기술이다.
  IEEE가 규정한 무선 LAN 규격은 802.11a 802.11b 802.11g 802.11n 802.11ac 등이다
  지금은 802.11n 802.11ac등을 주로 사용한다.
 무선 네트워크의 구성과 통신 방식을 설명할 수 있다.
  로컬 무선 LAN은 일반적으로 사무실에 전체적으로 무선을 설치한 것으로, 소규모의 단위 부서나 지사별로 사용 가능한 방식이다.
  무선 LAN의 기본 단위는 여러 개의 단말로 구성된 BSS(Basic Srevice Set)이며, 다음과 같이 분류된다
  에드혹 모드
  하부구조 모드
 무선 네트워크의 동작 방식을 설명할 수 있다.
  CSMA/CA는 802.11 개발자들이 무선 LAN을 위해 만든 액세스 프로토콜로서, 무선 환경에서 한 Statijon이 목적지로 데이터를 전송하기 위해 사용하는 프로토콜이다.
  SSID(Service Set Identifier)는 IEEE 802.11 표준으로 인터넷 사용자의 무선 네트워크 식별자이다.
